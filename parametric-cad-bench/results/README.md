# Results

Run outputs for the three tasks in this dataset, laid out exactly as Harbor writes them (`jobs/<job>/<trial>/…`). Every file here was produced by Harbor or the official CAD Bench verifier during a run. No file was added or edited by hand.

```
results/
  oracle/                  Oracle job (reference submitted as the answer): all 3 tasks score 1.0
  kimi-k3/
    lobed-rotor-image/     Kimi K3 job: 0.174
    hand-cannon-image/     Kimi K3 job: 0.035 (partial; see below)
    tray-bracket-image/    Kimi K3 job: 0.259 (partial; see below)
```

## Run settings

| | Oracle | Kimi K3 |
|---|---|---|
| Agent | `oracle` (runs `solution/solve.sh`) | mini-swe-agent 2.4.6, reasoning effort `max`, CAD Bench v3 leaderboard multimodal config |
| Model | n/a | `moonshotai/kimi-k3` through the Vercel AI Gateway |
| Attempts | 1 per task | 1 per task |
| Command | `harbor run -p . -a oracle` | see each job's `config.json` |

The Kimi K3 runs were made on the same tasks under earlier working names: `lobed-rotor-image`, `hand-cannon-v2-image` and `tray-bracket-image-v3`. Those use the same instruction, drawing, verifier, spec and reference as the tasks in this repo. The only differences were the name and a `--platform=linux/amd64` line in the Dockerfiles, which was needed to run on a Mac.

## What each file is

**Job level** (`<job>/`)

| File | Written by | Contents |
|---|---|---|
| `config.json` | Harbor | Job configuration: tasks, agent, model, agent settings, timeouts, environment |
| `result.json` | Harbor | Job summary: trial counts, mean reward, exceptions |
| `job.log` | Harbor | Job-level log |
| `lock.json` | Harbor | Resolved task digests and versions for the job |

**Trial level** (`<job>/<task>__<id>/`, one per attempt)

| File | Written by | Contents |
|---|---|---|
| `config.json` | Harbor | This trial's configuration |
| `result.json` | Harbor | Trial outcome: timings, reward, exception info |
| `trial.log` | Harbor | Trial log: environment build, agent run, verifier run |
| `lock.json` | Harbor | Resolved task digest for this trial |
| `exception.txt` | Harbor | Present only if the trial raised an error, e.g. the lobed-rotor agent timeout at 9,000 s |
| `agent/mini-swe-agent.txt` | Agent | Readable agent log: every step, command and output |
| `agent/trajectory.json` | Harbor | The agent run in Harbor's ATIF trajectory format |
| `agent/mini-swe-agent.trajectory.json` | Agent | mini-swe-agent's native trajectory, including the drawing images it viewed |
| `agent/oracle.txt` | Oracle agent | Oracle log |
| `artifacts/app/answer.py` | Agent | The FreeCAD script the agent wrote |
| `artifacts/app/answer.FCStd` | Agent | The FreeCAD model that gets graded |
| `artifacts/manifest.json` | Harbor | List of collected artifacts |
| `verifier/reward.json` | `tests/test.sh` | The task reward: `{"reward": …}` |
| `verifier/reward.txt` | `tests/test.sh` | The same reward as plain text |
| `verifier/reward_details.json` | `tests/run_scorer.py` | Score breakdown: `geometry_similarity`, `cad_spec_consistency`, `combined`, and the reasons, i.e. every geometry sub-score and the parameter counts |
| `verifier/answer.png` | `tests/test.sh` | Render of `answer.FCStd` (`freecad-validator render`); for review only, not scored |
| `verifier/test-stdout.txt` | `tests/test.sh` | Verifier console output (empty when nothing is printed) |

## Missing files (hand cannon and tray Kimi K3 runs)

The full job folders for these two runs were in a temporary directory that was cleared after the runs. Only the files that had already been copied out survived:
- `config.json` (job)
- `result.json` (trial)
- `artifacts/app/answer.py`, `artifacts/app/answer.FCStd`
- `verifier/reward.json`, `verifier/reward_details.json`, `verifier/answer.png`
- `agent/mini-swe-agent.txt`

These files are **not** available for those two runs:
- the job's `result.json`, `job.log` and `lock.json`
- the trial's `config.json`, `trial.log` and `lock.json`
- `agent/trajectory.json` and `agent/mini-swe-agent.trajectory.json`
- `artifacts/manifest.json`
- `verifier/reward.txt` and `verifier/test-stdout.txt`

The score and its full breakdown are in `reward.json` and `reward_details.json`, and the agent's every step is in `mini-swe-agent.txt`. A complete set can be regenerated by rerunning Kimi K3 on those two tasks.

Harbor's logs and configs contain absolute paths from the machine the runs were made on.
